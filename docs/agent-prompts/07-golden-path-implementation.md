# Prompt 07 — Golden Path Implementation

Implement only the approved golden-path slice.

The completed workflow must allow a valid business user to:

1. select a customer/order
2. create a job
3. schedule an appointment
4. assign an employee
5. start the job
6. complete the job
7. generate an invoice according to the approved rule
8. record a payment
9. see the resulting activity timeline

Enforce valid state transitions, authorization, tenant isolation, validation and transactional consistency.

Add meaningful tests.

Do not implement unrelated inventory, purchasing, HR, or advanced accounting features.
