# Prompt 01 — Build Foundation

Implement the approved foundation plan.

Scope only:
- solution/project structure
- EF Core configuration
- SQL Server configuration
- ASP.NET Core Identity
- Business/Organization
- BusinessUser
- initial roles/permissions foundation
- shared audit/activity foundation
- navigation shell

Follow AGENTS.md and docs.

Do not implement CRM, Sales, Jobs, Inventory, Finance or Reporting business workflows.

After implementation:
- build the solution
- run relevant tests
- report changed files
- report migration status
- report test/build results
- identify any remaining manual setup
