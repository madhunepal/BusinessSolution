# Prompt 03 — Customer Implementation

Implement the approved Customer management plan.

Requirements:
- follow existing architecture
- reuse existing UI patterns
- do not introduce new frameworks/packages
- enforce tenant isolation
- enforce authorization
- validate input
- record appropriate business activity
- add meaningful tests
- do not modify unrelated modules

Run build and relevant tests.

Return:
- summary
- changed files
- database/migration changes
- test results
- known limitations
