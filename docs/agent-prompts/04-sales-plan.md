# Prompt 04 — Sales Planning

Plan the first Sales vertical slice.

Scope:
Product/Service → Quote → Quote Items → Quote workflow → Sales Order → Sales Order Items → Quote conversion.

Important:
- Define valid Quote states and transitions.
- Define whether and when a Sales Order is created.
- Define what data is copied from Quote to Sales Order.
- Preserve historical quote data.
- Prevent invalid state transitions.

Do not modify files.

Return the domain model, workflow, database impact, UI impact, tests, and questions requiring approval.
