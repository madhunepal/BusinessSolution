# Prompt 08 — Senior Review

Review the current implementation as a senior .NET architect.

Do not modify files.

Check:
- architecture
- module boundaries
- domain logic
- EF Core queries
- async behavior
- transaction handling
- tenant isolation
- authorization
- validation
- security
- N+1 queries
- UI quality
- test coverage
- migration safety
- maintainability

Return only actionable findings grouped by severity:
Critical
High
Medium
Low

Do not praise the implementation unless necessary to explain a finding.
