## List Pages

Standard layout:

1. Page title
2. Primary action
3. Search
4. Filters
5. Data grid/table
6. Pagination
7. Row actions
8. Loading/error/empty states

## Detail Pages

Recommended sections:

- summary
- important actions
- related records
- activity timeline
- documents

## Forms

- labels must be clear
- validation errors should be near the field
- prevent accidental duplicate submission
- distinguish destructive actions
- show success/failure feedback

## Status

Use consistent badges/colors/icons only after a shared design system is established.

Never allow arbitrary status strings.

## Dashboard

Dashboard metrics should come from real transactional data. Avoid fake/demo metrics after the relevant module exists.
