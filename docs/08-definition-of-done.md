# Definition of Done

A feature is complete when all applicable criteria below are satisfied.

## Product

- [ ] User story/requirement is clear
- [ ] Acceptance criteria are defined
- [ ] Business workflow is documented if non-trivial

## Engineering

- [ ] Domain changes are correct
- [ ] Application logic is correct
- [ ] Persistence is correct
- [ ] UI is correct
- [ ] Validation is present
- [ ] Authorization is present
- [ ] Tenant isolation is verified
- [ ] Error handling is appropriate

## Quality

- [ ] Unit tests
- [ ] Integration tests where useful
- [ ] bUnit tests where UI behavior matters
- [ ] Build succeeds
- [ ] Relevant tests pass

## Operations

- [ ] Logging is adequate
- [ ] No secrets committed
- [ ] Migration is safe
- [ ] No unrelated files changed

## Documentation

- [ ] Relevant architecture/domain docs updated
- [ ] Backlog status updated
- [ ] Known limitations recorded
